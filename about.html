A SMARTER ME!

Play the game · Source repository

Game rule

Each run randomly samples five scenarios from a bank of 20. Each scenario has two choices whose screen positions are randomized.

scenario → two choices → record built-in choice label → repeat five times → advice or perfect-run role label

Topics

The scenario bank covers helping, sharing, tidying, honesty, calming down, hygiene, road and car safety, stove safety, manners, taking turns, helping family members and saving water.

Activation context

This game belongs to the same kids-* game set developed for the multi-game interactive children’s edutainment activation in the UAE.

Interpretation boundary

The game title does not imply a validated intelligence measure. The result is generated from five game choices and is not a validated measure of intelligence, personality, morality, social development or psychological traits.
